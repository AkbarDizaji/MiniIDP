Mini IDP

A local developer platform: generate a .NET API from a template, build it into a Docker image, and run it as a container on 127.0.0.1.

Create a service

3–30 characters: lowercase letters, digits and hyphens, starting with a letter.

  1. Generate source code from the bundled .NET API template
  2. Build a Docker image from its Dockerfile
  3. Start a container on a free localhost port
  4. Check /health until it answers
